# 🛒 E-Commerce Platform

A full-stack E-Commerce platform built using the **MERN stack**, with **EJS and Server-Side Rendering (SSR)** for the frontend.

The main goal of this project is not just to build an online store, but to understand how a real backend application is designed, structured, secured, and connected with a database.

---

- Express.js

---

## 📌 About The Project

This project is an E-Commerce platform where users can browse products, manage their cart, place orders, and manage their account.

The application will also have an **Admin system** where administrators can manage products, categories, users, and orders.

The project will use **Server-Side Rendering (SSR)** with EJS, so the server will generate HTML pages and send them to the browser.

The main focus of this project is the **backend architecture and concepts** behind the application.

---

# 👥 User Roles

The application will have different roles with different permissions.

### User

A normal user will be able to:

- Create an account
- Login and logout
- Browse products
- Search and filter products
- View product details
- Add products to cart
- Update cart
- Place orders
- View their orders
- Write reviews

### Admin

An admin will be able to:

- Manage products
- Manage categories
- Manage orders
- Manage users
- View basic store information
